# Launch checklist

## Required before opening applications

- GitHub repository: zkelvin80778/nittany-rover-team; Pages uses GitHub Actions.
- Verified team contact email.
- Working Penn State Microsoft Forms URL and designated reviewer access.
- Confirmed member details only if profile content is to be added.

## Deployment and application checks

- Complete the form checks in APPLICATION.md using a non-owner account.
- Confirm the contact route works and the collection notice names it.
- Recheck official URC rules and Q&A; replace the reference season only when the next rules are officially published. Update the year, download URL and checked date together.
- Read every page for accurate stage, target year, institution name and unsupported claims.
- Verify photo credits/license links and all external resources.
- Set the form URL/contact, then applicationsOpen if recruitment is open.
- GitHub Pages source must be Actions. Applications may remain closed while the public site is live.
- Confirm workflow success and inspect the deployed URL, HTTPS, images, routes, 404, canonical URLs and sitemap.

## Rollback and maintenance

Revert the offending commit on main to publish the previous build. To close recruitment, set applicationsOpen=false and stop accepting responses in Microsoft Forms. Do not remove existing responses or files as part of a website rollback.

Review rules before each recruitment season and when URC announces a new rule set. Keep target academic year separate from reference rules year. No recurring automation was created.

## Not verified locally

Live Microsoft account permissions, applicant isolation, actual résumé upload behavior, recipient contact delivery, public GitHub Pages HTTPS and real-domain routing cannot be verified until the required owner inputs are available.
